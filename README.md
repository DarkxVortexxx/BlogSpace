# ✍️ BlogSpace — Share Your Stories

BlogSpace is a full-stack blogging platform where users can create, explore, and share their stories.

## 🚀 Features

- User registration and login
- Create, edit, and delete blog posts
- Search and category filtering
- Like and bookmark posts
- Comment and reply system
- Personal dashboard
- User profiles with profile picture uploads
- Draft and published posts
- Reading time calculation
- Responsive UI for desktop and mobile

## 🛠️ Technologies Used

**Frontend**
- HTML
- CSS
- JavaScript

**Backend**
- Python
- Django
- Django REST Framework

**Database**
- SQLite

## ⚙️ Installation

1. Clone the repository:
   `git clone YOUR_REPOSITORY_URL`

2. Enter the project folder:
   `cd BlogSpace`

3. Create a virtual environment:
   `python -m venv venv`

4. Activate it:
   `venv\Scripts\activate`

5. Install dependencies:
   `pip install -r requirements.txt`

6. Create a `.env` file and configure:
   - `DJANGO_SECRET_KEY`
   - `DEBUG=True`

7. Run migrations:
   `python manage.py migrate`

8. Start the server:
   `python manage.py runserver`

9. Open:
   `http://127.0.0.1:8000/`
